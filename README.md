# Proyectos de electrónica aplicada

Selección de trabajos de [Lorhan Fernandes Ribeiro](https://github.com/LucarioFur). Esta página presenta su aplicación, mi participación y el estado de desarrollo. Los diseños comerciales se mantienen privados.

## Multisimulador para aire acondicionado inverter

**Estado: equipo en uso por clientes.**

Herramienta de diagnóstico para técnicos de climatización. Se comunica con unidades exteriores y permite comprobar la comunicación y consultar averías, ayudando a orientar la revisión del equipo en el lugar de trabajo.

Mi participación abarca el diseño electrónico, el firmware, la interfaz de usuario y la sujeción de la placa dentro de la carcasa. En una demostración disponible para entrevista se observa la indicación de una avería y su posterior desaparición al restablecer la condición del sensor.

## Interfaz para un equipo de prueba

**Estado: desarrollo con firmware implementado; demostración pendiente.**

Interfaz con pantalla TFT y encoder para navegar por menús, consultar información y enviar comandos a un controlador mediante UART. Trabajé en la presentación de datos, la interacción del usuario y el intercambio de mensajes, utilizando ESP32 en el entorno Arduino.

## Inverter-Link

**Estado: prototipos; validación de cada versión pendiente de documentar.**

Desarrollos para transportar comunicación serie por un enlace inalámbrico. He trabajado en dos implementaciones distintas: una con STM32WL y radio, y otra con ESP8266 y Wi-Fi. Este proyecto reúne integración de comunicaciones, gestión de datos y estados del enlace.
